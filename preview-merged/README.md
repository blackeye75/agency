# Homepage preview: merged (Crency × Copula)

One page combining the strongest parts of both references. Plain HTML/CSS/JS with GSAP and Lenis bundled in `vendor/`, so the folder works on its own.

```bash
cd preview-merged
python3 -m http.server 8000   # then open http://localhost:8000
```

## Look

Crency's deep purple and lilac as the base, Copula's orange and electric blue as the loud accents, Crency's lime as the highlight. One type system: **Bebas Neue** for display (Copula), **Mulish** for body, **Unbounded** for the odd wide letters (Crency's custom glyphs).

Everywhere: wavy section edges, the You / Click / Drag cursor, the arrow-swap button hover, the three-circle menu ("Open: Menu") and the colored-bands page transition on every link (all Crency).

Phones get a simpler layout (no pinned sections, no custom cursor); "reduce motion" shows everything static. Brand, clients, cases, stats and portraits are placeholders.
